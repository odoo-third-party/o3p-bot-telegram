O3P Bot Telegram

An Odoo 19 addon for Telegram Bot API configuration and quick operational tests.

Telegram Bot Token Recent Chats Send Message

Configuration

The Telegram bot token is stored in Odoo system parameters through the Settings app. The token field is available to system users only.

Test Console

The Telegram Bot menu opens a transient form that can list recent chats from getUpdates and send a message with sendMessage. The console does not create persistent bot chat records.
